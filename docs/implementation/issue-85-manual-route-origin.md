# Issue #85　地点詳細から手動出発地を選ぶ

地点詳細の「経路を確認」で目的地を固定し、「出発地を選択」（S04）に、その地図で屋外から出発できる公開地点を表示する。位置情報を使えない場合も同じ操作で案内できる。案内中は「出発地を変更」で同じ目的地を使う。別の地点の詳細を閲覧しているときは既存の「経路へ戻る」で案内に戻れる。

## 公開データと経路要求

- Map の地図・詳細・検索、S04 の候補、経路探索は同じ `PinnedBundleSource` を参照する。候補の読み込みから選択、探索、案内中のタブ再訪まで表示版を維持する。キャンセルして案内がないとき、または案内終了後は、次の Map 再訪で上流の版を取り込める。保存版を参照するシートには版の説明を表示する。
- 候補は `spots` の公開順。探索エンジンが各地点の正規 ID から解決した出発ノードが屋外にあることを条件にする。別の連結成分の地点や片方向制限のある地点は選べる。選択時の探索結果に従って未接続・到達不能を伝える。ID の大文字小文字、目的地と出発地の取り違えをテストしている。
- 受理された経路だけが案内を更新する。同一点・失敗なら通知を表示し、出発地を変えて解決できる場合に再選択ボタンを出す。シートを閉じると読み込み中の古い結果も破棄する。位置情報の理由画面にある「出発地を自分で選ぶ」は、閲覧中の地点、案内中の目的地、直前の再試行可能な目的地の順に引き継ぎ、該当がなければ Map の目的地検索を開く。
- 再選択シートでは案内中の目的地と一致する場合だけ現在の出発地に「選択中」を付ける。手動出発地クライアントの設定時だけ、要約の変更ボタンと失敗通知の再選択ボタンを表示する。両ボタンはラベルの折り返しに合わせて縦に広がり、カプセル形のタップ領域を持つ。
- 選択後は #34 の経路線・要約・既存案内バナー、#35 の屋外ステップ、PR #228 の出発・目的地マーカーを使用する。徒歩時間・距離・ステップは同じ探索結果から表示する。[経路線と要約](issue-34-route-polyline-summary.md) ／ [屋外ステップ](issue-35-outdoor-route-steps.md) ／ [マーカーの変更](https://github.com/m0o9l0v3/NexusMobile/pull/228)

## iPhone 17 Pro・iOS 26.5 での検証

2026-11-24 JST、端末 ID `32662B58-98F3-445B-8AD8-3735CAE33035`。Debug の `-NexusManualRouteCheck hgr_a -NexusLocationFixture denied` で、固定出発地を与えず格納庫Aの詳細から開始した。引数の地点 ID を省略しても格納庫Aを開く。数値と地名の組み合わせはすべて `RouteCheckFixtures` の画面検証用データで、地図とシートに注記を出す。本番では公開 bundle のみを参照し、検証注記は表示しない。

| 操作 | 確認した画面 |
| --- | --- |
| 地点詳細 → 経路を確認 | 現在地ボタンが位置情報オフを示した状態で S04 が開く。目的地「格納庫A」、検証注記、屋外候補を表示。格納庫Aの候補行には「目的地」を併記。 |
| 正門付近（検証用）を選択 | 両端の青・赤マーカーと折れ曲がる経路線、228 m・徒歩約3分。屋外ステップを展開すると出発、右折、左折、格納庫A到着の4件。 |
| 出発地を変更 → キャンセル | 目的地は格納庫A。正門付近の行にチェックと「選択中」があり、キャンセル後も228 mの案内を保持。 |
| 出発地を変更 → 技能審査棟 | 未接続の理由、「直線での案内は行いません」、再選択ボタンを表示。正門付近からの経路と要約を保持。 |
| 出発地を変更 → 教室棟 | 目的地は格納庫Aのまま、出発マーカー、経路線、要約を更新。272 m・徒歩約4分、屋外ステップ5件。 |
| 案内を終了 | 線、始終点マーカー、要約、通知が消え、通常の地点ピンを表示。 |
| ダーク・AX5 | S04 は大きいシートを使い、目的地、検証注記、行の補助表示を折り返す。候補・通知・要約をスクロールし、未接続通知の「出発地を選び直す」から再開できた。 |

`device_open` で開いた端末を `agent-device` で操作し、`device_screenshot` で描画を確認した。初回確認で要約が出発マーカーを隠したため、検索欄・要約・検証注記の外側に地図の高さを確保し、実寸が変わった時も経路を収めるようにした。AX5 では未接続通知の省略と「経路を確認」の文字切れを修正し、スクロール後に再選択ボタンの全文を読んで操作できた。ライト・標準文字サイズに復帰し、修正後に一連の経路変更を再確認した。VoiceOver のラベル・選択特性はシミュレーターのアクセシビリティツリーで確認した。実機での音声と読み上げ順は今後の確認項目。
