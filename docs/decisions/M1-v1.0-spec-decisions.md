## 2. テーマごとの詳細決定

### テーマ 1: #22（E2-7b オフライン保証）

1. **P05（初回起動時の同梱データ）**:
   - アプリ初回起動時のバイナリサイズ削減と、ビルド時データの陳腐化防止のため、アプリバンドル内に seed bundle は同梱しない。
   - 初回起動時はネットワーク接続を必須とし、一度取得した `ParticipantBundle` を端末内に保存する。
2. **保存版の有効期限**:
   - キャッシュの有効期間は「最終同期日時から 7 日間」とする。
   - 7日を超えた場合はデータを無効化し、通信できる環境での再同期を促すエラー画面を表示する。
3. **P06（オフライン時の経路再計算）**:
   - `RoutingGraph` は bundle に含まれており、探索処理（Dijkstra）は端末内で完結するため、オフライン環境でも新規探索・出発地変更・リルートを提供する。
   - ただし、突発的な通行止め等の最新情報が未反映であるリスクを明示するため、画面上部および経路要約カード内に「保存版（最新未確認）」バナーを表示する。

### テーマ 2: #49（E6-6 案内コンテンツ運用）＆ #86（案内画面・出典）

1. **U-1（原稿作成体制）**:
   - 学校側からの公式資料・原稿の提供を待つ。体制の正式決定は保留とし、原稿が揃った記事から順次取り込む。
2. **U-2（地点説明文）**:
   - v1.0 では誤情報防止を最優先とし、Spot の説明文（`description`）は未提供（空）とする。
3. **U-3（Figma UpdateStatus）**:
   - 画面上からは `UpdateStatus` を削除し、タイトルと本文のみのすっきりとした読み物レイアウトにする。
   - 品質管理のため、リポジトリ内の `GuidanceArticles.json` には `source`（出典）および `confirmation`（確認日・確認者）を保持する。
4. **目次・カテゴリ構造（P09）**:
   - 以下の 3 セクションで構成する：
     - ① **困ったとき・緊急**: 気分が悪くなったら（救護）、困ったとき（落とし物・総合案内）
     - ② **当日のご案内**: 受付のご案内、交通アクセス、施設利用・学食、注意事項
     - ③ **学校を知る**: 学科紹介、学校生活、学生寮、FAQ、このアプリについて
5. **国土地理院 測量成果の出典表示（E1-4 r4 K-3 §4.2）**:
   - 地図画面: 下部（Apple の Legal 表記の近傍）に常時見える 1 行表示「建物: 国土地理院 基盤地図情報（承認番号…）を使用・加工」を配置。
   - 情報画面: 案内タブの「このアプリについて」記事内に、測量法第30条に基づく承認文言全文を掲載。

### テーマ 3: 先行実装 UI／仕様（#27・#35・#85）

1. **タブ構造の 3 タブ再編（Home と探すの重複解消）**:
   - 検索対象を地点に絞ったことで「探す」タブと「Home 検索」の役割が重複していたため、**「探す」タブを廃止し、3 タブ構成（Home / Map / 案内）へ再編**する。
   - Home 画面内の検索バーをタップすると、Home 内でインラインに検索モード（カテゴリフィルター、履歴、地点一覧）が展開する（方式 B-1）。
   - 検索結果から地点を選んで Map タブへ遷移した後、Home に戻った際は前回の検索結果を保持する。キャンセルボタンまたは Home タブの再タップで通常 Home 画面に復帰する。
   - 詳細な UI/UX は Figma でモックアップを作成してから実装する（既存資産を積極活用）。
2. **#35（屋外ステップ案内 S06）**:
   - 経路要約カード内の折りたたみアコーディオン一覧（現行実装）を採用する。
   - 歩行時の安全と俯瞰性を優先し、手動の送りボタン（次へ/前へ）やステップごとの個別ズーム連動は設けない。
3. **#85（H-6 マップ遷移と S04 出発地選択）**:
   - Home やイベント詳細の「マップで見る」タップ時：唐突な画面切り替えを防ぐため、**まずその場でミニ地図・所要時間のプレビューシートを表示し、「案内を開始する」ボタンで Map タブへ遷移する 2 段階方式**を採用する。
   - S04「出発地を選択」シート：先行実装案（角丸シート、屋外候補一覧、再選択可能、AX5対応）を承認する。

### テーマ 4: #78（A11y 判断待ち）＆ #37 等の整理

1. **F-1（補足テキストコントラスト）**:
   - システムカラー `secondaryLabel`（約 3.4:1）を継続使用する。Apple HIG に準拠し、ユーザーが OS 設定で「コントラストを上げる」をオンにした際に自動で高コントラスト（7:1 以上）へ切り替わるため、標準の振る舞いとして許容する。
2. **F-5（AX5 時の見出し切れ）**:
   - アクセシビリティ文字サイズ（AX1〜AX5）時は、ナビゲーションバーのタイトルを `.inline` 表示に切り替え、見出しの末尾省略（「すべてのイ…」）を防止する。
3. **F-6（`EventAccent` オレンジの扱い）**:
   - Home の帯は情報伝達を担わない純粋な装飾として現状維持とする。
   - Map の選択中ピンの白抜き記号は、枠線付与や背景色の明度調整により、グラフィック基準である 3:1 以上を確保する。
4. **#37（E4-2 端末内経路探索エンジン）**:
   - Dijkstra アルゴリズム、配置、ユニットテスト（#76）を含む設計・実装を正式承認とし、ドキュメントを更新して Issue #37 のクローズ準備を完了とする。
