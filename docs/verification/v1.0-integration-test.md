**2026-11-25 時点は段階 A の先行確認まで。** 単体テスト677件と Release 無署名ビルドが成功した。画面監査に残っていた既知の失敗2テストは、2026-11-27 に解消した（[#78 の実施記録](ios-a11y-check.md#2026-11-27-画面監査の既知の失敗の解消)）。公式データ、現地歩行、TestFlight の正式受入結果は §7 にオーナーが追記する。[統合試験 #87](https://github.com/m0o9l0v3/NexusMobile/issues/87)・[リリース判定 #82](https://github.com/m0o9l0v3/NexusMobile/issues/82)

## 1. 目的・対象範囲・前提と判定ルール

来場者がホームで体験や施設を探し、マップで同じ地点を確認して屋外を歩き、案内記事へ戻れることを確かめる。現行は**ホーム／マップ／案内**の3タブで、検索はホーム内インライン検索とマップ検索で利用する（#27・PR #237）。E5 の屋内フロアマップ・屋内経路案内は後続版の対象（#223・PR #224）。受入対象は正式入口までの屋外案内である。[スコープ正本](../v1.0-scope.md)・[M1 仕様決定](../decisions/M1-v1.0-spec-decisions.md)

| 段階 | 実施条件 | 判定の扱い |
|---|---|---|
| A　先行確認 | シミュレーター、検証データ、単体試験、無署名ビルド、CI | 通過した試験と観察できた操作だけを記録する。今回の結果は §4。未確認の分岐は未実施のまま残す。 |
| B　正式受入 | 公式配信版、事前に確定した期待値、現地の実機、署名済み TestFlight ビルド | 端末・版・試験 ID ごとに期待値と実結果・証跡を照合する。失敗は不合格、前提未成立は保留。A の通過や Issue のクローズでは B を完了にしない。 |

公開記録には実施者の役割、公開版の ID、集計値、公開可能な証跡リンクを使う。座標（緯度経度・平面直角座標）、個人情報、秘密情報、未公開データを本文・画像・ログに記載しない。署名、App Store Connect への実アップロード、TestFlight 配布と最終公開判断はオーナーが行う。
