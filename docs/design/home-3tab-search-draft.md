## 1. 全体構造: 3 タブ構成への再編

「探す」タブと「Home 検索」の役割重複を解消し、v1.0 では **「ホーム」「マップ」「案内」の 3 タブ** に再編する。

| タブ | 表示名 | アイコン | 役割 |
|---|---|---|---|
| 1 | **ホーム** (`home`) | `house` | オープンキャンパス全体のダッシュボード。地点検索（インライン）、当日の開催日状況、次のイベント、案内ショートカット、この後のイベントタイムライン |
| 2 | **マップ** (`map`) | `map` / `MapTabIcon` | 構内屋外地図、現在地追従、14棟ポリゴン、地点ピン・詳細シート、手動出発地選択（S04）、屋外歩行経路・要約・ステップ案内 |
| 3 | **案内** (`guide`) | `info.circle` / `GuideTabIcon` | 困ったとき・緊急、当日のご案内（受付・アクセス・施設）、学校を知る（学科・学校生活・寮・FAQ）、このアプリについて（国土地理院出典） |

## 2. Home 画面の画面構成とインライン検索（方式 B-1）

### 2.1 平時（通常モード）の縦スクロール並び

1. **ヘッダー**: タイトル「Nexus」、サブタイトル「今日はどこへ行きますか？」
2. **検索エントリバー**:
   - 形状: カプセル型（幅いっぱい、高さ 56〜70 pt、角丸 Capsule、Elevation level1）
   - 表示: 虫眼鏡アイコン ＋ プレースホルダー「教室・施設・サービスを検索」
   - タップ動作: 別タブへ飛ばず、**Home 画面内で直接「検索モード」へ展開**する
3. **A. 開催日カード**（Elevation level3）:
   - 「8月1日（日）10:00〜15:00 開催中」（「15:00まで公開中です」等）
4. **次のイベント**（Elevation level3、左端に `EventAccent` オレンジ縦帯）:
   - 直近に開催されるイベント 1 件のサマリー（タイトル、時間、場所、マップで見るボタン）
5. **B. 案内ショートカット**（3件横並び）:
   - 受付 (`reception`)、困ったとき (`help`)、アクセス (`access`) への直通カード
6. **この後のイベント**（横スクロールカード、最大10件）＋「すべて見る」リンク:
   - 時間順のイベントカード（タイトル、時間、会場、マップで見るボタン）

---

### 2.2 検索モード（インライン展開時）

検索バーをタップした際、Home のイベント一覧がスッと隠れ、検索用コンテンツがインライン展開する。

```
┌────────────────────────────────────────┐
│ [ 🔍 教室・施設・サービスを検索  ✕ ] [キャンセル] │
├────────────────────────────────────────┤
│ [すべて] [教室] [施設] [サービス]        │
├────────────────────────────────────────┤
│ （未入力時: 検索履歴 または 主要施設一覧） │
│  🕒 2A教室                             │
│     教室棟 2F                          │
│  🕒 Da Vinci Hall                      │
│     Da Vinci Hall 1F                   │
├────────────────────────────────────────┤
│ （入力時: リアルタイム絞り込み結果一覧）    │
│  📍 2A教室                             │
│     教室棟 2F                          │
│  📍 2B教室                             │
│     教室棟 2F                          │
└────────────────────────────────────────┘
```

1. **検索バーの変化**:
   - キーボードが競り上がり、検索バーの右側に「キャンセル」ボタンがフェードイン。
   - 入力文字がある場合はクリアボタン（✕）を表示。
2. **カテゴリフィルター**:
   - 検索バー直下に水平スクロールまたはチップで配置（「すべて」「教室」「施設」「サービス」）。
3. **検索結果・履歴**:
   - 未入力時: 最近検索した地点の履歴（履歴クリアボタン付き）。履歴がなければ初期の全地点一覧。
   - 入力時: 部分一致でリアルタイムに地点一覧を絞り込み。
   - 同名地点: 「多目的室 / 教室棟 1F」「多目的室 / 教室棟 2F」のように建物・階数を必ず補助テキストに明記。
4. **地点選択時の挙動**:
   - 地点行をタップすると、**Map タブへ自動遷移し、該当地点にピンを立てて地点詳細シートを展開**する。
   - **裏側で Home の検索状態（検索語・カテゴリ・結果一覧）は保持**される。
5. **平時（通常 Home）への復帰出口**:
   - 出口 ①: 検索バー右の「**キャンセル**」をタップ。
   - 出口 ②: 下部タブバーの「**ホーム**」アイコンを再タップ（iOS 標準のタブ再選択によるリセット）。

## 3. H-6 「マップで見る」の 2 段階プレビューシート

Home 画面やイベント一覧の「マップで見る」ボタンを押した際、唐突なタブ切り替えによる体験の断絶を防ぐため、**2 段階遷移（プレビューシート → 案内開始で Map タブ遷移）** を採用する。

```
┌────────────────────────────────────────┐
│               ── [バー] ──             │
│  Da Vinci Hall                         │
│  Da Vinci Hall 1F                      │
│                                        │
│  ┌──────────────────────────────────┐  │
│  │     [ ミニ地図プレビュー ]         │  │
│  │   🔵 (現在地/正門) ─── 🔴 (目的地) │  │
│  └──────────────────────────────────┘  │
│  徒歩 約2分 (140 m)                    │
│                                        │
│  [ 案内を開始する ] (Primary ボタン)     │
│  [ 閉じる ]                            │
└────────────────────────────────────────┘
```

1. **第 1 段階: プレビューハーフシートの表示**
   - 「マップで見る」タップ時、画面が薄く暗転し、下からハーフシートがスムーズに展開。
   - ミニ地図（目的地ピン＋青い経路ポリライン）、場所名、徒歩所要時間・距離を表示。
   - 参加者はその場で大体の位置と距離感を確認できる。
   - シートを下にスワイプするか「閉じる」を押せば、元のイベント画面に留まる。
2. **第 2 段階: 案内開始による Map タブ遷移**
   - シート内の「**案内を開始する**」ボタンをタップすると、初めて Map タブへ画面が切り替わり、全画面のナビゲーション・ステップ案内モードに突入する。

## 4. 案内タブの 3 分類目次（P09）

案内タブは、利用動機に合わせて以下の 3 つの視覚的セクションで構成する。
各記事詳細画面からは `UpdateStatus`（更新状況バッジ）を削除し、タイトルと本文のみの清潔な読み物レイアウトとする（確認日・出典は内部 JSON で管理）。

1. **第 1 セクション: 困ったとき・緊急（最上部に赤・橙のハイライト表示）**
   - 気分が悪くなったら（救護室・AED・体調不良時の緊急連絡）
   - 困ったとき（総合案内所・落とし物・迷子）
2. **第 2 セクション: 当日のご案内（オープンキャンパス当日の行動支援）**
   - 受付のご案内（受付場所・配布物・整理券）※Home ショートカット直通
   - 交通アクセス（シャトルバス・駐車場・最寄り駅）※Home ショートカット直通
   - 施設利用・休憩所（学食・休憩スペース・自動販売機）
   - 注意事項・マナー（構内撮影ルール・飲食）
3. **第 3 セクション: 学校を知る（進学検討・学校理解のための読み物）**
   - 学科紹介（各学科の特色・カリキュラム）
   - 学校生活（年間行事・部活動・1日の流れ）
   - 学生寮・下宿案内（設備・費用・周辺環境）
   - よくある質問（FAQ）
   - **このアプリについて（権利表記・出典）**
     - 国土地理院 測量成果の利用承認文言全文（承認番号含む）を掲載。
