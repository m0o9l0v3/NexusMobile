# 野帳（現地測量）

[構内の建物の現地測量の計画](campus-survey-plan.md) で使う野帳。

- **スマートフォンで記入する（推奨）**: [`map-data/survey/templates/field-sheet.xlsx`](../../map-data/survey/templates/field-sheet.xlsx) を Google ドライブにアップロードし、Google スプレッドシートで開く（オーナーのドライブには「野帳 v2（構内の現地測量）」として作成済み。古い「野帳（構内の現地測量）」は距離だけの版なので使わない）。種類・点・建物・機材・左右は一覧から選ぶ。右端の「確認」、シート「点」の観測の数、シート「棟ごと」の直角の確かめ、シート「照合」の古い棟の合否が、その場で自動で出る。終わったらシート「CSV」をカンマ区切り形式でダウンロードすると、ツールが読む形になる。
- 古い棟の角（`<ID>-G*`）と国土地理院の辺の長さを入れた版は、`make-field-sheet-xlsx.py --gsi <gsi-buildings.geojson> --out <リポジトリの外>` で作る（計画書 §11）。国土地理院の座標が入るので、この版はリポジトリに置かない。
- 印刷するとき: [field-sheet.html](field-sheet.html)（A4 横、ブラウザーで開いて印刷）。

以下は紙の野帳と同じ内容。入力は [`map-data/survey/templates/field-sheet.csv`](../../map-data/survey/templates/field-sheet.csv) と同じ列に写す（計画書 §8.3）。

- 人の名前は書かない。`測った人` には、オーナーが決めた役割名か頭文字を書く。
- 距離は **水平距離**（m、小数3桁まで）。斜めに測ったときは測った長さをそのまま書き、`傾斜°` か `高低差 m` を足す（ツールが水平に直す。計画書 §4.5）。読み上げ → 記録 → 読み返し。
- 測り直した行は消さない。`無効` 欄に理由と新しい記録番号を書く。
- 点の名前: 新しい棟の角 `<ID>-P1…`、古い棟の角（基準点） `<ID>-G1…`（国土地理院の頂点の順）、ノード `campus_n_001…`、入口 `<ID>_ent_001…`、曲がり角 `B01…`、仮の点 `T1…`、確かめの点 `K1…`。

## 観測の種類

| 種類 | いつ使う | 書く列 |
|---|---|---|
| 距離 | 2点の間を巻尺・レーザーで測る | 測った点、どこから、距離（斜めなら傾斜か高低差） |
| 支距 | 基線（ノードからノード）をウォーキングメジャーで進み、累積距離の所から直角に点まで測る（計画書 §4.2） | 測った点、基線、累積距離、支距、左右（基線の進む向きに見て）、機材（累積距離）、支距の機材 |

- 累積距離は、その基線の起点のノードからの距離で書く。ノードで次の基線に移るたびに、ウォーキングメジャーを 0 に戻す（計画書 §5.1）。
- 斜めに測った距離は、右端の「水平距離 m（自動）」に水平に直した値が出る。「照合」「棟ごと」はこの値で判定する。
- 支距は直角に下ろす（直角プリズムか、3-4-5 で確かめる）。15 m を超える支距は、その点に距離を1本足す。
- 何の点か（`physical_point`）には「北東の角の柱」「正面入口の中央」など、後で同じ所が分かる言葉を書く。
