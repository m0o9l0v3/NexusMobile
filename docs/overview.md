# 公開サイト（`web/`）の方針

この文書は `web/` 固有の方針と状況を説明する詳細文書である。v1.0 全体の包含・除外とリリース条件は [Nexus v1.0 スコープ定義](v1.0-scope.md) を正とする。

## 目的（2026-10-25 改訂）

`web/` は、次を掲載する公開サイトとする（[GitHub Issue #131](https://github.com/m0o9l0v3/NexusMobile/issues/131)、2026-10-25 利用者決定）。v1.0 のリリース条件に含める。

- アプリ（iOS）の告知
- 開発状況
- サーバー状況
- 開発に伴う技術説明

v1.0 の参加者向けアプリ機能は iOS アプリに限定する。`web/` は参加者向けアプリの代替ではなく、iOS と機能同期しない。この境界の決定経緯は [GitHub Issue #7](https://github.com/m0o9l0v3/NexusMobile/issues/7) を参照する。

以前の「イベント告知 LP へ再構成する」方針（[GitHub Issue #81](https://github.com/m0o9l0v3/NexusMobile/issues/81)）は、実装されないまま Close されていた。#81 で決めるとしていた事項は #131 へ移した（#81 の 2026-10-25 のコメント）。

## 現在の状況

方針転換前の参加者向け PWA（Home / Map / Events、地図、AI サポート、ログ送信）は 2026-10-25 に削除した。現在の `web/` は、Vite・React・Tailwind の構成と、準備中であることだけを示す1ページである。旧 PWA は git 履歴から参照できる。

## 決めてから実装すること（#131）

- **サーバー状況**：何を出すかとデータ源。内部構成・ホスト名・版など、攻撃の手掛かりになる情報は出さない
- **開発状況**：出典（GitHub のマイルストーン・Issue から作るか、手で書くか）
- **技術説明**：公開してよい設計情報の範囲。秘密情報・個人情報・個人を特定できる粒度の位置情報は出さない
- **公開先とデプロイ**：ホスティング先、ドメイン、HTTPS（NexusInfra との分担）
- **QR パラメーター**：`?code=XXXX` の着地点、有効値、無効・未知コード、未指定時の挙動。v1.0 の QR は resource link だけに使う（[v1.0 スコープ定義](v1.0-scope.md)）
- **API の利用**：`GET /api/events/today` などの public-api を使うか

## 環境変数

- 現在の `web/` のコードは環境変数を参照しない。API を使うときに `VITE_API_BASE_URL` などを定める。
- Public API の定義は `openapi/public.yaml` を参照する。

## 対象外

- iOS アプリと同等の参加者向け Web アプリの提供
- iOS アプリとの機能同期
- チェックイン、参加者プロフィールの収集・ローカル保持
