# 公開サイトに載せる文章（`web/content/`）

お知らせと開発状況は、ここに Markdown で手で書きます（#131、2026-11-14 決定）。更新したらサイトを作り直して配信します。

- 1件を1ファイルにする。ファイル名は `2026-11-20-maintenance.md` のように日付から始める
- ファイル名が `_` で始まるものは載せない（下書き用）
- 読む人向けの言葉で書く。Issue 番号・ホスト名・版・内部の事情は書かない

## お知らせ（`notices/`）

```markdown
---
date: 2026-11-20
kind: maintenance
---
## 11/22 21:00〜22:00 メンテナンス

この時間は、アプリで地図データを新しくできません。すでに取り込んだ地図はそのまま使えます。
```

`kind` は `maintenance`（メンテナンス）・`incident`（障害）・`info`（お知らせ）のどれか。

本文で使える書き方は、段落・`- ` の箇条書き・`**太字**`・`[文字](https://...)` だけです。
